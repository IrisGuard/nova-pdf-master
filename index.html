Why local-first

Some documents should never touch a server.

Contracts, medical records, payslips, ID scans, client files. Uploading them to a free converter means trusting an unknown machine with the original. NOVA PDF removes that decision: the engine is downloaded once, and the file is processed on your own hardware.

01

The file stays in the tab

PDF.js and pdf-lib operate on an in-memory copy. Closing the tab wipes it. There is no upload endpoint to leak, log or retain.

02

No account, no paywall

Every tool is available on first load. No sign-up wall in front of “download”, no watermark stamped onto your work.

03

Honest engineering

Text stays selectable, signatures are real PDF objects, encryption is AES-256, and redaction physically removes content instead of drawing a box over it.

How it works

Three steps. No round trip.

1

Open a PDF or image

Drag it anywhere, or use the file picker. Password-protected PDFs ask for the password locally.

2

Choose a tool

Search with Ctrl K, tune the options, and watch a live page preview when placement matters.

3

Download the result

The output is generated in memory and saved by your browser. The original is untouched.

Engine

Mozilla PDF.js for rendering and text extraction, pdf-lib for writing real PDF objects and AES-256 encryption.

OCR

Tesseract compiled to WebAssembly. Language models are cached after the first run, then OCR works offline.

Offline

A service worker caches the workbench and its fonts. Use “Make available offline” once for the complete engine.

Verifiable

Open DevTools → Network while processing a file. You will see no request carrying the document.

Questions

Straight answers.

Are my PDF files uploaded to a server?

No. NOVA PDF runs PDF.js, pdf-lib and Tesseract in your browser. Your document stays in the tab's memory and is never sent anywhere. You can confirm it in the browser's Network panel: there are no upload requests.

Is NOVA PDF free?

Yes. Every tool is free, with no account, no watermark and no file-size limit imposed by us. The only limit is the memory of your own device.

Does it work offline?

Yes. Install NOVA PDF as a PWA or use the offline copy button once. After the engine is cached, the workbench starts and processes files without a connection.

Is the redaction permanent?

Yes. Redaction flattens the page at high resolution, paints the selected areas black, and rebuilds the PDF, so the covered text and images no longer exist in the output file.

Which encryption is used?

AES-256 (PDF 2.0 revision 6), with separate user and owner passwords and permission flags for printing, copying, editing, annotations and form filling.

Can it read scanned PDFs?

Yes. OCR rasterises each page locally, recognises the text with Tesseract, and writes an invisible text layer back into a searchable PDF. English, Greek, German, French, Spanish, Italian, Portuguese and Dutch are included.

Which browsers are supported?

Current Chrome, Edge, Firefox and Safari on desktop. Mobile browsers work for smaller files; very large documents need desktop memory.

Do you keep analytics or logs?

No document content, filenames or metadata is transmitted. The application is static and performs no telemetry calls.
